# Founding neighborhood

These fourteen standalone primitive-only modules were authored with Codex during app development. They are checked-in starter buildings, not runtime timing samples. `npm run seed` validates them before adding missing plots; it preserves viewer buildings and cached, unchanged seeds.

The seed manifest is the source of the founding neighborhood. Every module uses the shared midnight teal, warm cream, mint and peach palette. None needs an asset download, texture, model or account.
